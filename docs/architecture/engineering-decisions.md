## 2. Top Technical Decisions (상세 6대 의사결정)

### ADR-001: 뇌파 생체 신호와 상담 발화의 다중 모달 결합 및 정량 괴리도(Discrepancy) 수식 도입

- **Decision**:  
  아동·청소년의 정서 상태를 판정할 때 인터뷰 텍스트 단독에 의존하지 않고, VR 환경의 뇌파 생체 신호에서 산출된 안정도(`stability`)와 상담 발화의 긍정성 점수(`verbal_positivity`)를 결합한 괴리도 수식 `(1.0 - stability) * verbal_positivity`를 정의하고, 이중 임계값(`stress > 0.60` 및 `verbal_positivity > 0.60`) 충족 시 잠재적 우울/방어기제 경보를 발생시킴.
- **Why**:  
  아동·청소년 내담자는 상담사에게 잘 보이고자 하는 사회적 바람직성 편향(Social Desirability Bias)이나 감정 억압으로 인해 힘든 상황에서도 "기분이 아주 좋아요", "문제없어요"라고 긍정적으로 진술하는 경향이 짙음. 텍스트 분석만으로는 이러한 '가면성 우울(Smiling Depression)'을 감지할 수 없어 신체 자율신경계 반응(뇌파 스트레스/이완)과의 상호 대조가 필수적임.
- **Trade-off**:  
  생체 신호 텍스트 로그 파싱과 언어 데이터 추출의 2원화된 전처리를 동기화해야 하는 엔지니어링 복잡도가 증가함. 반면 겉으로 드러나지 않는 심리적 위기 아동을 조기에 객관적으로 선별할 수 있는 임상적 신뢰성을 확보함.

### ADR-002: Meta Llama 3.3 70B(Groq API) + Meta Llama 3.1 8B Instruct(4-bit QLoRA) 하이브리드 파이프라인

- **Decision**:  
  인터뷰 전문에서 정서·대상·강도를 구조화하는 단계에는 Meta의 Llama 3.3 70B를 Groq API 모델 ID `llama-3.3-70b-versatile`로 호출한다. 정형 EEG 데이터 기반 서술형 임상 요약에는 로컬 `meta-llama/Meta-Llama-3.1-8B-Instruct`를 4-bit NF4로 양자화하고 LoRA 어댑터($r=32, \alpha=16$)를 적용한다.
- **Why**:  
  두 단계의 요구사항이 다르기 때문이다. 상담 전사록 구조화는 긴 문맥과 은유 해석을 위해 대형 모델의 추론 성능을 활용하고, 반복 실행되는 정형 요약은 로컬 8B 모델로 수행하여 외부 API 의존성과 GPU 메모리 사용을 분리한다. 여기서 Groq는 모델 제작사가 아니라 Meta Llama 3.3 70B의 추론 제공자이며, 로컬 모델은 7B가 아니라 코드와 저장된 PEFT 어댑터 기준 **Meta Llama 3.1 8B Instruct**이다.
- **Trade-off**:  
  클라우드 경로는 네트워크 및 `GROQ_API_KEY`에 의존하고, 로컬 경로는 CUDA/VRAM 및 PEFT 런타임에 의존한다. 반면 한 경로의 제약이 다른 단계 전체를 지배하지 않도록 역할을 분리할 수 있다.

### ADR-003: 한국어 임상 특화 SBERT 기반 시맨틱 유사도 토폴로지 구축

- **Decision**:  
  상담 텍스트의 키워드 간 관계를 단순 형태소 빈도(TF-IDF)나 사전 기반 매칭으로 분류하지 않고, 한국어 사전학습 임베딩 모델 `jhgan/ko-sbert-multitask` 및 `ko-sroberta-multitask`를 활용하여 코사인 유사도를 산출하고, 임계값 0.60(노드 간 연결) 및 0.25(메인 감정-키워드 연결)를 기준으로 동적 의미망을 구성함.
- **Why**:  
  내담자 발화는 "노란색 기분", "숨이 턱 막힘"과 같은 비유적 표현이 빈번하며, "친구와 비즈 거래(긍정)"와 "강요된 거래(부정)"처럼 동일한 단어가 완전히 반대되는 감정 맥락에서 사용됨. 고정 어휘 사전으로는 이러한 맥락을 분별할 수 없음.
- **Trade-off**:  
  형태소 토큰 카운팅 대비 임베딩 추론에 약 0.5~1초의 추가 연산 시간이 소요됨. 그러나 의미론적 유사성을 정밀 반영하여 노드 간 불필요한 노이즈 엣지를 차단하고 핵심 감정 원인 인과망을 명확히 시각화함.

### ADR-004: ForceAtlas2 물리 엔진 기반 대화형 토픽 네트워크 시각화 및 자동 정지(Auto-Freeze)

- **Decision**:  
  토픽 네트워크 렌더링에 PyVis를 채택하고 ForceAtlas2 물리 엔진(`gravitationalConstant: -80`, `springLength: 150`, `springConstant: 0.08`)을 적용하되, 1,000회 시뮬레이션 안정화 완료 후 1,200ms 경과 시 브라우저 내 물리 계산(`physics.enabled: false`)을 강제로 정지시킴.
- **Why**:  
  노드가 30개 이상 밀집될 경우 물리 엔진이 상호 반발력과 인력 간의 평형을 찾지 못하고 브라우저 화면에서 노드가 계속 진동하거나 바깥으로 튕겨 나가는 발산(Explosion) 현상이 발생하여 클라이언트 브라우저 CPU를 100% 점유함.
- **Trade-off**:  
  화면 정지 후 사용자가 노드를 재배치할 때 탄성적인 물리 반응이 지속되지 않음. 그러나 레이아웃 붕괴를 원천 방지하고 1.2초 내에 깔끔하게 정돈된 그래프 상태에서 확대·축소 및 호버 툴팁 탐색을 안정적으로 보장함.

### ADR-005: Russell 정서 모델 기반 6대 뇌파 지표 차원 축소 및 단계별 가중합(0.2:0.3:0.5) 보존 법칙

- **Decision**:  
  측정된 6가지 뇌파 지표(`stress`, `engage`, `relax`, `excite`, `interest`, `focus`)를 Russell 정서 모형에 기반하여 정서가(Valence), 각성도(Arousal), 과제 몰입도(TE)로 차원 축소하고, VR 세션 진행 단계(Step2: 0.2, Step3: 0.3, Step4: 0.5)의 정규화 가중합을 적용함.
- **Why**:  
  VR 기기 착용 초기(Step2)에는 낯선 환경에 대한 일시적 긴장과 생소함으로 지표가 불안정함. 반면 세션 후반부(Step4)는 과제에 적응하여 본연의 정서 반응이 뇌파에 반영됨. 단순 평균을 취할 경우 초기 적응 노이즈가 과대 반영되어 임상 판단을 왜곡함.
- **Trade-off**:  
  단일 시점 데이터만 존재하거나 특정 Step이 누락되었을 때 가중치를 재조정하는 예외 분기가 필요함. 그러나 시간에 따른 심리 적응 곡선을 통계적으로 보정하여 일관되고 재현 가능한 정서 지표를 도출함.

### ADR-006: 결함 격리형 8단계 순차 실행 파이프라인(Fail-Safe Pipeline Orchestration)

- **Decision**:  
  전체 분석 파이프라인을 3단계 전처리(EEG 변환, 상담 분석 2종)와 8단계 출력(자기인식 그래프, 지표 테이블, 레이더 차트, 요약, 워드클라우드, 토픽망, 괴리 분석, 최종 보고서)으로 모듈화하고, 각 단계마다 독립적인 `try-except` 예외 격리와 누락 파일 감지 폴백을 배치함.
- **Why**:  
  연구 및 현장 환경에서는 HWP 파일 포맷 손상, 외부 LLM API 일시 지연, GPU 가속 환경 부재 등 다양한 런타임 결함이 발생할 수 있음. 이전 단계의 실패가 전체 시스템의 비정상 종료(Crash)로 이어져서는 안 됨.
- **Trade-off**:  
  단계 간 에러 메시지 로깅과 결측 시 대체 안내 텍스트 처리 코드가 증가함. 반면 결함이 발생한 특정 시각화 컴포넌트만 우회하고 나머지 분석 결과와 대시보드를 제공할 수 있는 결함 격리성을 확보함.
